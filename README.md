# ARK0B-1

**Live:** https://ark0b.github.io/Portfolio/

## Overview 

This is a portfolio website. 
For reasons that seemed sensible at the time, it's also a chip.

The chip has since grown a datasheet: each major project gets its own page, with the figures, the numbers, and the parts that didn't work.

## Features 

- Interactive SVG die map, one core per project, each with a status LED
- Datasheet-inspired UI, down to the errata table
- Case-study pages with real screenshots and results
- Real-time clock, set to IST
- Keyboard navigation
- Works with JavaScript turned off, which no chip has ever been asked to do
- Built with vanilla HTML, CSS, and JavaScript
  
## Tech Stack 

- HTML
- CSS
- JavaScript
- SVG
- Chai (power supply, not the assertion library)
